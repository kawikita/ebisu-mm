# アプリケーション起動・コマンド仕様書

## 1. 概要

本ドキュメントは、Ebisu APIアプリケーションのコマンドラインオプション仕様と、アプリケーション起動からサーバ稼働開始までの処理フローをまとめたものです。

---

## 2. コマンドラインオプション仕様

### 2.1. コマンド構造

アプリケーションは`clap`を利用したサブコマンド方式で起動します。

- `ebisu_api [COMMAND] [OPTIONS]`

#### サポートされるコマンド

| コマンド         | オプション         | 説明                                      |
|------------------|--------------------|-------------------------------------------|
| (なし)           | -                  | APIサーバを起動                           |
| export           | --file `<FILE>`    | OpenAPI仕様をJSONでエクスポート           |
| version          | --verbose          | バージョン情報を表示（詳細表示も可）      |

#### 例

- サーバ起動: `ebisu_api`
- OpenAPIエクスポート: `ebisu_api export --file openapi.json`
- バージョン表示: `ebisu_api version --verbose`

---

## 3. アプリケーション起動フロー

1. **コマンドライン引数のパース**
    - `clap`により`Cli`構造体へパース
    - サブコマンドが指定されていれば該当処理へ分岐

2. **サブコマンド処理**
    - `export`:
        - `exporter::export_openapi_json`を呼び出し、OpenAPI仕様を指定ファイルへ出力
        - 成功時は標準出力に出力先のパスを表示
    - `version`:
        - `version::show_version`を呼び出し、バージョン情報を表示
    - (サブコマンドなし):
        - サーバ起動フローへ

3. **サーバ起動フロー**
    1. `.env`ファイルの読み込み（dotenv）
    2. ロガー初期化（`logging::init_logger()`）
    3. 起動メッセージ出力（log/info）
    4. データベース接続プール作成（`get_db_pool()`）
    5. DIコンテナ（`AppModule`）生成
    6. Actix Webサーバ構築・ルーティング設定
        - ルート、accounts API、swagger UI等
    7. サーババインド（アドレス・ポートは環境変数またはデフォルト値）
    8. サーバ起動・非同期で待機
    9. Ctrl+C等で停止時、終了メッセージ出力

---

## 4. 環境変数

- `SERVER_ADDRESS` : サーバのバインドアドレス（デフォルト: 127.0.0.1）
- `SERVER_PORT`    : サーバのバインドポート（デフォルト: 8180）
- `DATABASE_URL`   : SQLite接続URL（デフォルト: sqlite:./ebisu.db）
- `DATABASE_MAX_CONNECTIONS` : DBコネクションプール最大数（デフォルト: 5）
- `LOG_FILE_PATH`  : ログファイル出力先（デフォルト: ./logs/ebisu_api.log）

---

## 5. 補足

- サーバ起動時は`info`レベルで起動・停止メッセージが出力されます。
- OpenAPIエクスポートやバージョン表示はサーバを起動せず即時終了します。
- ルーティングやDI設計の詳細は`src/utils/app_setup.rs`等を参照してください。
